## 5-1. 면회 예약 (2026-08-01 기획)

**배경**: 현재 면회는 아무 때나 방문해도 받아드린다(돌려보낼 수 없음). 따라서 예약은
방문을 제한하는 장치가 아니라 **"기다림 없이 면회하도록 돕는 권장 절차"**로 포지셔닝한다.
예약의 실익은 직원 쪽에 있다 — 방문 예정을 미리 알면 어르신을 프로그램에서 미리
모셔오고, 면회가 한 시간대에 몰리는 것을 분산하고, 어르신 상태가 안 좋은 날 미리
연락드릴 수 있다.

**단계별 도입**:

1. **1단계 — 네이버 예약 (무료)**: 네이버 스마트플레이스에 시설 등록 후 예약 기능 활성화.
   결제가 없는 예약이라 수수료 0원. 슬롯(요일·시간대·팀 수)·접수 알림·확정/거절을
   네이버가 처리. 요청사항 입력란에 "어르신 성함과 관계"를 받는다.
   부수 효과: 보호자 대부분이 네이버 검색·지도에서 출발하므로 검색 노출 자체가 개선됨.
   개인정보는 네이버가 처리하므로 사이트의 법적 부담 없음.
2. **2단계 — 자체 예약 시스템 (수요 검증 후)**: 네이버 예약 이용량이 실제로 많으면
   Supabase 기반으로 신청 → 직원 확정 → 문자 안내 흐름을 자체 구축하고 관리자 페이지에
   통합. 개인정보처리방침 게시 의무, 알림톡/SMS 비용 발생. **수요 확인 전에는 만들지 않는다.**

**사이트 반영**: 입주안내 하위에 "면회 안내" 페이지 신설 — 면회 시간, 예약 방법
(네이버 예약 버튼 자리 + 전화 병기), 면회 규칙(감염 증상 시 연기, 음식물 반입 사전 문의,
사진 촬영 동의 등). 예약 버튼은 스마트플레이스 등록 전까지 "준비 중" 처리.
문구 원칙: "예약 없이 오셔도 면회하실 수 있습니다"를 반드시 병기.

**시설(고객) 확인 사항** — `docs/시설-요청자료-안내문.md` 로 발송:
① 스마트플레이스 등록(사업자등록증 필요) 후 작업자 계정 멤버 초대(비밀번호 공유 금지)
② 면회 슬롯 단위(30분/1시간)와 시간대당 동시 면회 팀 수
③ 면회 장소(별도 공간 여부 — 슬롯 정원 산정에 필요)
